# paper-v1: "Two Old GPUs and a Glass Box"

The exact code and data behind the paper submitted to the Kaggle Gemma 4 Developer Agent paper track
(2026-11-12).

- **The paper:** [`competitions/gemma4-swe-agent/paper/paper.md`](../../competitions/gemma4-swe-agent/paper/paper.md)
- **Every number, mapped to its script:** [`paper-reproduction.md`](../../competitions/gemma4-swe-agent/docs/paper-reproduction.md)
- **Reproduce:** `bun install && bun run paper-numbers`
- **The toolkit:** capture, step replay and fork, sealed score reads, noise statistics and a local dashboard
  (`bun run dashboard`), for any OpenAI-compatible agent.

Apache-2.0. The data is anonymised. No prompts, task text or submission settings are included.
